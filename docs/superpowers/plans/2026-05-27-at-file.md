# at-file Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a VS Code extension that completes workspace files and directories after `@`.

**Architecture:** Keep VS Code API wiring thin and place testable behavior in small modules. Use `workspace.findFiles` for scanning, cache results, and invalidate when workspace files change.

**Tech Stack:** TypeScript, VS Code Extension API, Mocha, Node assert.
